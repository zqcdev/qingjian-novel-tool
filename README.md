## 📖 项目简介

**青简**是一款面向网文创作者的 AI 写作辅助工具（Windows 客户端），定位是"让 AI 真正懂你的小说"。它不是简单的文本生成器，而是一套覆盖**从构思、设定、大纲、章节到定稿全过程**的创作系统，帮助作者在长篇连载中保持设定一致、剧情不漂移、质量可把控。

## ✨ 核心功能

### 1️⃣ 17 步全流程创作工作流
从灵感构思、世界观设定、人物小传、故事大纲，到章节细纲、正文生成、质检修复、定稿输出，17 个步骤环环相扣，把"写小说"拆解为**可执行、可追踪**的流程。适合新手快速上手，也适合老手规范化生产。

> 想法提炼 → 世界观 → 人物构建 → 金手指 → 总纲 → 卷纲 → 细纲 → 章节大纲 → 正文撰写 → 去 AI 味 → 结构诊断 → 评分 → 质检自查 → 自动修复 → 红线审查 → 定稿入库 → 台账归档

### 2️⃣ 本地 LanceDB 知识库
人物、设定、伏笔、剧情线全部沉淀在本地向量知识库中，写作时自动检索调用，保证长篇连载中**前后设定一致、人物不崩、伏笔可回收**。知识库永久免费，数据完全存放在本地。

### 3️⃣ 质检自动修复闭环
生成内容后自动进行质量检查，发现问题并进入自动修复流程，形成 **"生成 → 质检 → 修复 → 再质检"** 的闭环，只改被点名的段落，减少人工逐段校对的工作量。

### 4️⃣ SKILL 技能系统
以技能模块的方式扩展写作能力，内置网文写作技能包（爽点设计、去 AI 味、结构诊断、评分系统等），不同题材、不同写作任务可调用不同技能，系统可持续扩展。

### 5️⃣ 八层防剧情漂移体系
针对网文长篇连载最痛的"写着写着跑偏"问题，构建八层防护机制，从设定锚定、知识库检索、红线扫描到质检修复层层把关，让剧情始终沿着大纲推进。**百万字长篇的剧情一致性，从"凭记忆"变成"凭体系"。**

### 6️⃣ 🆕 快捷站点面板
客户端内弹窗直达常用 AI 工具与发布平台，无需在浏览器间反复切换；提示词按当前小说自动生成，开箱即用，进一步压缩码字之外的琐碎操作。

### 🔒 另附三大长篇刚需能力

- **角色动态档案**：每章定稿自动更新角色的境界、位置、身体与心理状态、持有物；写审时自动检测 OOC（角色言行出戏），人设几百章不崩。
- **伏笔台账管理**：每章蓝图承诺的悬念与关键事件，定稿后自动对照正文核查，漏埋的伏笔、忘收的钩子逐条提示，再也不会挖坑不填。
- **多版本 + 修订快照**：每章保留完整版本历史，每次润色、修复都存快照，哪一版不满意一键回滚，改崩了也丢不了稿。

## 🛠 模型配置

### 🤖 AI 生成模型（以 DeepSeek 为例）

1. 打开 [platform.deepseek.com](https://platform.deepseek.com)，手机号注册后充值（10 元即可写几十万字）
2. 进入「API keys」→ 创建 API Key 并复制（只显示一次）
3. 客户端「设置 → AI 生成模型」→ 添加模型 → 服务商选 DeepSeek（地址参数自动填好）→ 粘贴 Key → 模型选 `deepseek-chat` → 保存并设为默认

### 📖 向量模型（硅基流动，免费）

1. 打开 [cloud.siliconflow.cn](https://cloud.siliconflow.cn)，注册即送体验额度，向量模型个人使用**免费**
2. 左侧「API 密钥」→ 新建并复制
3. 客户端「设置 → 向量模型」→ 添加模型 → 服务商选硅基流动 → 粘贴密钥 → 模型选 `BAAI/bge-m3` → 保存并设为默认

> 其它国内外厂商（智谱、通义、Kimi、MiniMax 等）均可接入，配置方法类似；客户端「设置」内含图文版教程与更多厂商配置说明。

## 💬 常见问题

<details>
<summary><b>Q1：数据真的不上传吗？</b></summary>

书稿、设定、本地 LanceDB 知识库全部保存在你自己的电脑上，**不上传、不丢失**；调用大模型时也仅把当前需要的上下文片段发给模型服务商，青简本身不中转、不存储你的正文。
</details>

<details>
<summary><b>Q2：没有 API Key 能用吗？</b></summary>

青简采用"自带 Key"模式，**必须自备大模型 Key** 才能跑通生成环节。推荐 DeepSeek（10 元可写几十万字）+ 硅基流动（向量模型免费）的组合，整体成本可控；平台**零抽成**，消耗多少 tokens 一目了然。
</details>

<details>
<summary><b>Q3：免费版和完整版差别在哪？</b></summary>

免费版开放 17 步工作流的**前 5 步**（想法提炼 → 总纲），可完整体验创作链路起点；专业版解锁全部 17 步 + 质检自动修复闭环 + 高密度爽点规范与大神技法。本地知识库与 SKILL 技能系统免费版即可使用。
</details>

<details>
<summary><b>Q4：写百万字长篇，怎么避免剧情前后矛盾？</b></summary>

由**八层防剧情漂移体系** + 本地 LanceDB 知识库共同保障：剧情要点时间线、前文结尾无缝衔接、知识库向量召回、源头设定对账、骨架信号六轴核对、结构性矛盾审查、伏笔健康扫描、红线审查层层兜底，写到 300 章再提 50 章前的旧设定也能精准召回。
</details>

<details>
<summary><b>Q5：AI 写的稿子能直接过平台审核吗？</b></summary>

青简内置**本地确定性红线扫描**，提前排查敏感触发词、标点硬伤、无主语短句滥用等违规内容，降低过审驳回概率；但平台签约标准因网站而异，稿子仍需作者本人审读与二次润色。
</details>
