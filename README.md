# 小说创作辅助工具

#### 介绍
青简是什么
青简是面向网文创作者的 AI 写作辅助工具（Windows 客户端 v1.2.1），核心功能包含 17 步全流程创作工作流、本地 LanceDB 知识库、质检自动修复闭环、SKILL 技能系统、八层防剧情漂移体系， 以及今天刚上线的 快捷站点面板：客户端内弹窗直达 AI 工具与发布平台，提示词按当前小说自动生成。
